# Expense Tracker

A simple Python Expense Tracker that allows users to enter expenses, calculates the total spending, and displays the average expense.

## Features

- Add multiple expenses
- Calculate total spending
- Calculate average expense
- Handles invalid input

## Technologies Used

- Python

## How to Run

```bash
python expense_tracker.py

Sample Output

Enter expense (or 'done' to finish): 100
Enter expense (or 'done' to finish): 50
Enter expense (or 'done' to finish): done

Expense Summary

Number of Expenses: 2
Total Spent: 150.0
Average Expense: 75.0
